# Bank-Loan-Analytics-Dashboard
1. Bank Loan Analytics Dashboard -- Power BI
An end-to-end Bank Loan Analytics Dashboard built in Microsoft
Power BI to analyze loan applications, funding, repayments, loan
status, interest rates, and borrower risk indicators.

2. Project Overview
The objective of this project is to create a comprehensive bank loan
report that helps monitor lending activity and portfolio performance.
The dashboard presents key loan metrics and trends in an interactive
format to support data-driven analysis and lending decisions.

3. The project contains two main dashboard views:
- Summary -- High-level KPIs and good vs. bad loan performance.
- Overview -- Detailed visual analysis of loan status, funded
  amount, repayments, interest rate, and DTI ratio.
  
4. Key Metrics
The dashboard includes:
- Total Loan Applications
- Total Funded Amount
- Total Amount Received
- Average Interest Rate
- Average DTI Ratio
- Good Loan Applications
- Bad Loan Applications
- Funded Amount vs. Repayment
- Loan Status
- Average Interest Rate by Loan Status
- Average DTI Ratio by Loan Status
The dashboard also provides filters for loan purposes such as Car,
Credit Card, Debt Consolidation, Educational, Home Improvement, House,
Major Purchase, Medical, Moving, Other, Renewable Energy, Small
Business, Vacation, and Wedding.

5. Dataset
The project uses the Financial_loan_data.xlsx dataset.
The dataset contains 38,576 loan applications and includes fields
such as:
- ISSUE_DATE
- ID
- PURPOSE
- VERIFICATION_STATUS
- GRADE
- HOME_OWNERSHIP
- ADDRESS_STATE
- LOAN_STATUS
- EMP_LENGTH
- EMP_TITLE
- LAST_CREDIT_PULL_DATE
- LAST_PAYMENT_DATE
- NEXT_PAYMENT_DATE
- MEMBER_ID
- SUB_GRADE
- TERM
- ANNUAL_INCOME
- DTI
- INSTALLMENT
- INT_RATE
- LOAN_AMOUNT
- TOTAL_ACC
- TOTAL_PAYMENT

6. Dashboard Highlights
Summary Dashboard
The Summary page provides a quick view of the overall loan portfolio,
including:
- Total applications
- Total funded amount
- Total amount received
- Average interest rate
- Average DTI ratio
- Good vs. bad loan distribution
- Funded amount and repayment comparison
- Loan status distribution

7. Overview Dashboard
The Overview page provides a more detailed analysis of loan performance
and borrower-related metrics using interactive charts and filters.

8. Tools & Technologies
- Microsoft Power BI -- Data modeling, calculations, interactive
  dashboards, and visualization
- Microsoft Excel -- Source dataset
- PowerPoint -- Project/problem-statement documentation

9. How to Use
- Install Microsoft Power BI Desktop.
-  Download or clone this repository.
- Open Bank Loan Analytics Dashboard.pbix.
- If Power BI asks for the source file, point it to
   Financial_loan_data.xlsx.
- Refresh the data if required.
- Use the available filters and dashboard navigation to explore the
   loan portfolio.
   
10. Project Goal
The main goal of this project is to transform raw loan data into an
interactive analytical dashboard that makes it easier to:
- Monitor lending performance
- Understand good and bad loan distribution
- Compare funded amounts with repayments
- Analyze interest rates and DTI ratios
- Identify loan-status trends
- Support data-driven lending decisions
